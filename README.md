## 🛒 E-commerce Web App

Aplicación web de e-commerce desarrollada con JavaScript y React.
Permite navegar productos, agregarlos al carrito y completar un flujo de compra básico.

## 🚀 Live Demo
https://voidfull-store.vercel.app

## 🛠️ Tecnologías utilizadas
- JavaScript (ES6+)
- React
- HTML5
- CSS3
- Firebase
- MercadoPago
- Git & GitHub
- Vite
- Tailwind

## ✨ Funcionalidades
- Catálogo de productos
- Carrito de compras
- Integración de pagos con MercadoPago
- Consumo de APIs
- Manejo de estado y componentes
- Deploy funcional

## 📌 Objetivo del proyecto
Desarrollar una aplicación de e-commerce completamente funcional, orientada a cubrir necesidades reales de un negocio digital. El proyecto incluye flujo de compra, gestión de productos e integración de servicios externos, con foco en una experiencia de usuario clara, rendimiento y escalabilidad.
